PROJETO OVERLEAF - T2 SCAN CHAIN

1. No Overleaf, crie um projeto novo por Upload Project.
2. Envie o arquivo T2_Overleaf.zip inteiro.
3. O arquivo principal ja se chama main.tex.
4. O projeto usa IEEEtran e pgfplots, ambos disponiveis no Overleaf.
5. As figuras usadas pelo main.tex estao em figures/.
6. O CSV consolidado esta em data/results_final.csv apenas como registro dos dados.

Antes da entrega:
- inserir o link final do repositorio no local desejado, caso o grupo queira mostra-lo no relatorio;
- conferir se o professor deseja algum formato de capa diferente do IEEE;
- revisar nomes e acentuacao dos autores.
